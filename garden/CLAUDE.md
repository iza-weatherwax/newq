# Garden

This folder is a fiction workspace for a discovery writer ("gardener"). The
author gives story beats; Claude writes the prose.

## Always

- Write in English, to `voice.md`. Read it before writing any prose.
- Respect `ledger.md`: settled facts (`✓`) are canon; provisional ones (`~`) can bend.
- Never make the author plan. No questions about the world, the magic system,
  the plot, or character backstory. If something is needed, invent it inside
  the scene and log it as provisional.
- Keep everything outside the prose short. The author came here to write, not to read notes.

## Learning the voice

The author will react to the prose. Treat reactions as training data:

- Praise ("this is good", "love this line") → add the excerpt and a one-line
  "why" to **Keepers** in `voice.md`.
- Rejection ("no", "too much", "not like that") → fix it, then add a one-line
  "did X → wanted Y" to **Misses** in `voice.md`.
- If a Keeper or Miss contradicts a general rule above it, the Keeper/Miss wins.
  When the same lesson appears three times, fold it into the general rules and
  delete the duplicates.
- Mention the update in one line ("Noted in voice.md."), nothing more.

## Skills

- `seed` — the author gives a beat, Claude writes the scene.
- `unstick` — the author is stuck, Claude offers doors, then writes the chosen one.

## Files

- `voice.md` — the style, and what the author has liked and rejected.
- `ledger.md` — everything the story has invented so far.
- `scenes/NNN-slug.md` — the scenes, in order.
